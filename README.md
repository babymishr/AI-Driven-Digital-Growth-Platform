# Student Idea Sharing Platform

A React-based web application where students can share ideas, engage with posts, and manage content through an intuitive user interface.

## Features

- Create, edit, and delete ideas
- Like and comment on posts
- Responsive and mobile-friendly UI
- Component-based architecture
- Dynamic state management using React Hooks
- Clean and reusable code structure

## Tech Stack

- React.js
- JavaScript (ES6+)
- CSS3

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/student-idea-sharing-platform.git
```

2. Navigate to the project folder

```bash
cd student-idea-sharing-platform
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

The application will run on:

```
http://localhost:5173
```
